# Fictional lease editor evidence

These synthetic ten-page PDFs are **not Leslie's master**, legal templates or
completed reference leases. Every source page is labeled FICTIONAL ORIGINAL.
The invented blank two-column test area exists only in the fixtures; its map
must never be imported for an Oaktown original. No private tenant/staff data is
included. All signature areas remain blank and all PDF metadata says DRAFT.
