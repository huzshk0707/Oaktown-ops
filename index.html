          2. 

        2. Confirm details. Check rent, beds/baths, available amenities, utilities, pets, lease terms, deposit, availability and source dates. Ask Leslie for missing information. Do not borrow features from another unit.
          3.

          4. 

        4. Get Leslie’s approval. Keep the approved full description unchanged. Only then use the Website features prompt to produce the companion ALL-CAPS feature lines.
